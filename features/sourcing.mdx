Search in plain language, not keyword strings, and get candidates ranked for the specific job, not a generic profile score.

## Built on real reach

Staffer searches a large, continuously updated candidate database, not just whoever's applied to you. Every result is scored against that job's actual criteria, so the same person can rank differently for two different roles, because they should.

## Multiple rounds, one conversation

Search rarely nails it in one pass. Ask for a different angle, widen the net, narrow it, and the agent runs another round without losing what you already found. Tell it what to do with the results directly: add the top five, drop anyone outside a timezone, shortlist everyone above a score. No clicking through a list one row at a time.
