The candidate view shows one candidate in one job. It has five tabs, a profile panel and an actions menu.

## Open it

Click a row on a job's **Candidates** tab, the workspace-wide **Applications** page, or a conversation in **Messages**. Opening from Messages lands you on the **Messages** tab directly. Opening from a list lands on **Process**.

## The header

- A stage badge (for example an eye icon and **In review**).
- **Not contacted** / **Contacted** and a consent indicator (**No consent**, **Consent · this job** / **workspace** / **future roles**, or **Consent expired**). You can't click them. See [Get contact details](/companies/contact-details) for what they mean.
- Two score circles, current and potential, hidden until the candidate has a score. See [How match scores work](/companies/match-scores).
- **Next application** / **Previous application** arrows to move through the list you opened this candidate from. The **J** and **K** keys do the same, except while you're typing in a field.
- The **Candidate actions** (…) menu.

## The five tabs

| Tab | What's on it |
|---|---|
| **Process** | The recommended next step, often with a message ready to send, followed by this candidate's process steps: upcoming, completed, and their original application. See [Next actions](/companies/recommended-actions). |
| **Match** | Their score against every criterion in the brief, current and potential, with the reasoning behind each one. |
| **Messages** | Your message thread with them, and the composer to write a new one. |
| **Notes** | What your team has recorded about them. See [Notes](/companies/notes). |
| **Activity** | Every event on this candidacy, in order: stage changes, messages sent and received, steps started and completed. A few events, such as moving a candidate back a stage, can show a technical label instead of a sentence. |

## The profile panel

A panel next to the tabs shows: match score, engagement (only if they're also saved to the talent pool), seniority, function, experience, location, languages, work type, work mode, relocation, LinkedIn, email, phone, and open-to-work status, plus a **Request contact info** button. Hide or show it with the **Hide profile** / **Show profile** button in the header.

## Tell me more

Click **Tell me more** (the sparkles icon) on the profile panel to ask the agent about this candidate. It sends a message naming them to the job's chat, and opens the chat panel if it's hidden.

## Candidate actions menu

| Action | What it does |
|---|---|
| **Copy ID** | Copies the candidate's profile ID. |
| **Copy application link** | Copies their private application link. Only available once they're promoted. |
| **Rescore** | Re-runs their match score against the current brief. See [When scores change](/companies/editing-and-rescoring). |
| **Save to talent pool** / **Remove from talent pool** | Saves or removes this profile from your workspace's talent pool, independent of this job. |
| **Mark as contacted** / **Undo mark as contacted** | Records, or un-records, that you reached them outside Staffer. See [Get contact details](/companies/contact-details). |
| **Move to stage…** | Moves them to a different stage. See [Change a candidate's stage](/companies/candidate-state). |
| **Move to job…** | Moves their candidacy to a different job. See [Change a candidate's stage](/companies/candidate-state). |
| **Remove** | Takes them off this job. Reversible. See [Change a candidate's stage](/companies/candidate-state). |
| **Permanently remove** | Removes them and blocks them workspace-wide. See [Change a candidate's stage](/companies/candidate-state). |

## Application snapshot and live profile

On the **Process** tab, the candidate's original **Application** card has a **Review snapshot** button. It opens the copy of their profile Staffer saved when they were promoted or applied. That copy never changes, so you can always see what you reviewed. The profile panel next to the tabs shows their current profile, so the two can differ if they've changed jobs or updated their skills since.

## Scouting results use a smaller panel

A search result you haven't promoted yet opens a smaller profile panel instead of this view. It has no tabs, because there's no application yet. See [Search for candidates](/companies/running-a-search).

## Common questions

<AccordionGroup>
  <Accordion title="Why doesn't this candidate have a Process or Match tab?">
    They haven't been promoted yet. Until then, you only get the smaller profile panel on the **Scouting** tab.
  </Accordion>
  <Accordion title="Can I move between candidates without going back to the list?">
    Yes. Use the arrows in the header, or **J** and **K**, to step through the list you opened this candidate from.
  </Accordion>
  <Accordion title="What's the difference between the snapshot and the profile panel?">
    The snapshot is the profile as it was when they were promoted or applied, and it never changes. The profile panel is always current.
  </Accordion>
  <Accordion title="Do the Not contacted or No consent labels do anything if I click them?">
    No. They only show status.
  </Accordion>
</AccordionGroup>
