Every job on Staffer starts as a conversation, not a form. Click **New job** and describe the role to the agent in the chat panel.

## Describe the role

Tell the agent what you're hiring for: title, team, location, seniority, and anything else you know. You don't need to cover everything in one message.

After a few exchanges, usually one to three, the agent has enough to sketch a first draft. It opens the brief on the canvas with its best guess at every field it can infer, using sensible defaults for the rest.

<Note>
  Nothing is saved to your jobs list until the agent opens that first draft. An empty chat with no job description yet creates nothing.
</Note>

## Refine it in chat

Keep talking to the agent to adjust the draft: change the title, add a criterion, tighten the location. Each instruction updates the brief on the canvas right away, so you can see the effect of what you just said.

You can also edit the brief directly. See [The brief: hard fields and criteria](/companies/brief-criteria).

## Start from an existing job

If a new role is close to one you already have, tell the agent something like "start from the Senior Backend Engineer job, but make it junior and remote." It reads the source job's fields and criteria, applies your change, and opens a new draft instead of starting blank.

For an exact copy with no changes, ask to duplicate the job instead. Duplicating also carries over the listing and the process steps, not just the brief.
